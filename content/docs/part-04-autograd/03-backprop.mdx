## Chain Rule in Action

Expression: `L = (a × b + c)²`

```mermaid
flowchart BT
    L["📉 L"]:::loss --> S["²"]:::op
    S --> P["+"]:::op
    P --> M["×"]:::op
    M --> A["a"]:::leaf
    M --> B["b"]:::leaf
    P --> C["c"]:::leaf
    classDef loss fill:#EF4444,color:#fff,stroke:#B91C1C
    classDef op fill:#0EA5E9,color:#fff,stroke:#0369A1
    classDef leaf fill:#4F46E5,color:#fff,stroke:#3730A3
```

Backward (bottom-up in diagram = reverse topo order):

```
∂L/∂L = 1
∂L/∂(square input) = 2 × input × ∂L/∂L
∂L/∂a = ∂L/∂(ab) × b
∂L/∂b = ∂L/∂(ab) × a
∂L/∂c = ∂L/∂(sum) × 1
```

## Worked Example

`a=2, b=-3, c=10` → inner = 2×(-3)+10 = 4 → L = 16

## Why Topological Sort?

Operation order matter — parent-এর `_backward()` call হওয়ার **আগে** child-এর grad ready থাকতে হবে:

```
Wrong order: parent._backward() before child.grad set → wrong gradients
Right order: reverse topo ensures child processed first
```

## Debugging Tips

Gradient zero? Check:
- `_backward` rule correct?
- Topo sort order correct?
- Forgot to call `.backward()`?

## ✅ তুমি কী শিখলে?

- **Backprop** = reverse topological traversal + chain rule
- Output node seeded with `grad = 1`
- Each `_backward()` distributes gradient to parents
- Topological sort ensures correct order
- Enables training networks with millions of parameters

# 🔄 Module 4: Autograd

Neural network **train** করতে হলে model-কে বলতে হবে: "তোমার weight একটু বাড়ালে loss কমে না কমে?" — এটাই **gradient**।

<Callout type="idea">
💡 **Autograd** = forward pass-এ graph বানাও, backward pass-এ chain rule দিয়ে gradient বের করো। Andrej Karpathy-র **micrograd** idea-টাই follow করব।
</Callout>

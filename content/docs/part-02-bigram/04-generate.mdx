# Sentence Generate

<ConceptAnim name="next-token" caption="Generate: i → like → apple → is → fruit …" />

এখন সবচেয়ে মজার অংশ — model দিয়ে **নতুন sentence generate** করা।

## Idea: Autoregressive Generation

একটা word দিয়ে শুরু করো, তারপর বারবার predict করো:

```mermaid
flowchart LR
    start["Start: i"] --> p1["predict → like"]
    p1 --> p2["predict → apple"]
    p2 --> p3["predict → is"]
    p3 --> p4["predict → fruit"]
    p4 --> p5["predict → is"]
    p5 --> loop["fruit ↔ is loop / maxLen"]
    classDef start fill:#4F46E5,color:#fff,stroke:#3730A3
    classDef step fill:#10B981,color:#fff,stroke:#047857
    classDef warn fill:#F59E0B,color:#fff,stroke:#D97706
    class start start
    class p1,p2,p3,p4,p5 step
    class loop warn
```

Argmax দিয়ে typical result: `"i like apple is fruit is fruit …"` (max length পর্যন্ত)।

## Step by Step (argmax)

Count table অনুযায়ী:

```
Step 1:  "i"                → "like"   → i like
Step 2:  …like              → "apple"  → i like apple
Step 3:  …apple             → "is"     → i like apple is
Step 4:  …is                → "fruit"  → i like apple is fruit   (fruit:3 > healthy:1)
Step 5:  …fruit             → "is"     → … fruit is
Step 6:  …is                → "fruit"  → … is fruit  (loop until maxLen)
```

<Callout type="warn">
⚠️ Bigram-এর limitation: `is → fruit` এবং `fruit → is` — argmax **loop** করে। Real LLM-এ EOS token / max length দিয়ে stop করা হয়।
</Callout>

## Generation Loop

1. শেষ word নাও  
2. Predict করো (argmax)  
3. নতুন word যোগ করো  
4. Repeat — next না পেলে **বা** `maxLen` পৌঁছালে stop

## GPT-ও same process

```
Input: "The capital of France is"
→ predict → "Paris"
→ predict → "."
→ predict → (stop)
```

শুধু GPT-এর prediction অনেক বেশি smart (Transformer + Attention)।

## তুমি কী শিখলে?

- **Generate** = repeatedly predict next word
- **Autoregressive** = আগের output পরের input
- Argmax generate = deterministic (সবসময় same)
- Bigram loop সম্ভব — তাই sampling / EOS দরকার

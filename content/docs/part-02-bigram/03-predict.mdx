# Predict (Argmax)

<ConceptAnim slug="part-02-bigram/03-predict" />

Training শেষ — count table আছে। এখন model দিয়ে **predict** করব, মানে একটা current word দিলে next word বলব। সবচেয়ে simple strategy: যার count সবচেয়ে বেশি, সেটাই pick করো। এই pick-কে বলে **argmax**।

## Argmax = সবচেয়ে বেশি count

আমাদের table থেকে কয়েকটা উদাহরণ:

```
predict("i")     →  "like"    (count=3, একমাত্র option)
predict("like")  →  "apple"   (count=2, সবচেয়ে বেশি)
predict("apple") →  "is"      (count=1)
predict("fruit") →  "is"      (count=1)
```

`like`-এর পরে banana বা mango-ও সম্ভব — কিন্তু argmax সবসময় highest টানে, তাই বারবার `apple`।

তাহলে কী হয়? Distribution আছে, কিন্তু argmax সেই distribution-এর চূড়াটাই নেয় — বাকি option উপেক্ষা করে।

## কোড

Count table থেকে probability বের করে argmax pick — নীচের snippet ও Playground-এ input দিয়ে next word দেখো।

<CodeRun title="Argmax predict" height={220}>{`// Count table থেকে সবচেয়ে বেশি count pick
const counts = {
  i: { like: 3 },
  like: { apple: 2, banana: 1, mango: 1 },
};

function predict(word: string): string {
  const row = counts[word as keyof typeof counts] ?? {};
  let best = '';
  let bestCount = -1;
  for (const [w, c] of Object.entries(row)) {
    if (c > bestCount) {
      best = w;
      bestCount = c;
    }
  }
  return best;
}

log.step('Argmax predict');
for (const w of ['i', 'like']) {
  log.data(w + ' →', predict(w));
}
log.ok('highest count pick');`}</CodeRun>

## তুমি কী শিখলে?

- **Predict** মানে count table থেকে সবচেয়ে likely next word বলা
- **Argmax** = highest probability/count pick করা — deterministic, কিন্তু বৈচিত্র্য কম
- Model এখন training data-র pattern follow করে; একাধিক option থাকলেও argmax একটাই রাখে

# Predict (Argmax)

Training শেষ। এখন model দিয়ে **predict** করব — মানে next word বলব।

## Argmax = সবচেয়ে বেশি count

সবচেয়ে simple strategy: যার count সবচেয়ে বেশি, সেটাই pick করো।

```
predict("i")     →  "like"    (count=3, একমাত্র option)
predict("like")  →  "apple"   (count=2, সবচেয়ে বেশি)
predict("apple") →  "is"      (count=1)
predict("fruit") →  "is"      (count=1)
```

## কোড

```ts
predict(word: string): string | null {
  const row = this.table.get(word);
  if (!row) return null;

  let bestWord = '';
  let bestCount = -1;

  for (const [next, count] of row) {
    if (count > bestCount) {
      bestWord = next;
      bestCount = count;
    }
  }

  return bestWord;
}
```

## Probability Function

```ts
probabilities(word: string): Map<string, number> {
  const row = this.table.get(word);
  const total = sum of all counts;
  return count / total for each next word;
}
```

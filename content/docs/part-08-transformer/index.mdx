# Module 8 — Transformer Block

Module 7-এ Attention শিখলে — কিন্তু Attention alone দিয়ে GPT বানানো যায় না। Building block-এ আরও কয়েকটা piece লাগে: **Positional Encoding**, **LayerNorm**, **FFN**, আর **Residual** connections।

এই Module-এ সেগুলো একসাথে জোড়াব — শেষে একটা full **Transformer Block** পাবে, যেটা Module 9-এ stack করে Mini GPT হবে।

<Callout type="idea">
Transformer Block = Attention + MLP + Norm + Residual — GPT Nটা block stack করে।
</Callout>

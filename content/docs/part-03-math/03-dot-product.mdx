## Geometric Intuition

```mermaid

    B["📐 Vector b"]:::vec --> D
    D --> S["🔢 Scalar score"]:::scalar
    classDef vec fill:#7C3AED,color:#fff,stroke:#5B21B6
    classDef dot fill:#F59E0B,color:#fff,stroke:#D97706
    classDef scalar fill:#10B981,color:#fff,stroke:#047857
```

Geometric formula:

```
a · b = ‖a‖ × ‖b‖ × cos(θ)
```

- **θ = 0°** (same direction) → maximum positive
- **θ = 90°** (perpendicular) → zero
- **θ = 180°** (opposite) → negative

## Similarity Example

```
apple  = [0.8, 0.2, 0.1]
fruit  = [0.7, 0.3, 0.0]
car    = [0.1, 0.9, 0.8]

apple · fruit = 0.62  ← high (similar meaning)
apple · car   = 0.34  ← low (different meaning)
```

Embedding space-এ semantically similar words-এর dot product বেশি হয়।

## Attention Connection

Self-attention-এ:

```
score(i, j) = Query[i] · Key[j]
```

Query token `i` Key token `j`-কে কত "relevant" মনে করে — dot product দিয়ে measure।

## ✅ তুমি কী শিখলে?

- **Dot product** = element-wise multiply + sum → একটা scalar
- High dot product মানে vectors similar / aligned
- Attention score = Query · Key dot product
- Same dimension লাগে — না হলে error

# LLM কীভাবে কাজ করে?

<ConceptAnim slug="part-01-tokenizer/01-llm-kivabe-kaj-kore" />

একটা LLM আসলে **"next token prediction machine"**।

মানে, তুমি কিছু text দিলে সে বলে: "পরেরটা কী হওয়া উচিত?"

## উদাহরণ

তুমি লিখলে `i like` — model ভাবে:

```
apple   → 50% chance
banana  → 25% chance
mango   → 25% chance
```

তারপর একটা pick করে → `apple`। আবার context বাড়ে: `i like apple` — এভাবে sentence তৈরি হয়।

এই Module-এ আমরা pipeline-এর **প্রথম অংশ** করব: Tokenizer → Vocabulary → Encoding → Training Pairs।

## GPT-4 vs আমাদের Model

| | GPT-4 | আমাদের Tiny Model |
|---|---|---|
| Training data | Trillions of tokens | ~30 words |
| Vocabulary | ~100,000 tokens | 12 words |
| Parameters | Billions | ~144 (Module 2) |
| Architecture | Transformer | Bigram (Module 2) |

স্কেল আলাদা, কিন্তু **idea একই**।

## তুমি কী শিখলে?

- LLM = next token prediction machine
- Input → Model → Probability → Pick one token
- আমরা ছোট scale-এ same idea implement করব

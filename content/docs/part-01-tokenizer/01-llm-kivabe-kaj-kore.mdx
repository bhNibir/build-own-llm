# 🧠 LLM কীভাবে কাজ করে?

<ConceptAnim name="next-token" caption="Context দেখে model পরের token-এর probability বের করে" />

একটা LLM আসলে **"next token prediction machine"**।

মানে, তুমি কিছু text দিলে সে বলে: "পরেরটা কী হওয়া উচিত?"

```mermaid

    model --> banana["🍌 banana 25%"]:::out
    model --> mango["🥭 mango 25%"]:::out
    classDef input fill:#4F46E5,color:#fff,stroke:#3730A3
    classDef process fill:#10B981,color:#fff,stroke:#047857
    classDef out fill:#F59E0B,color:#fff,stroke:#D97706
```

## উদাহরণ

তুমি লিখলে:

```
i like
```

Model ভাবে:

```
apple   → 50% chance
banana  → 25% chance
mango   → 25% chance
```

তারপর একটা pick করে → `apple`

আবার:

```
i like apple
```

Model ভাবে:

```
is → 100% chance
```

এভাবে একটার পর একটা word generate করে পুরো sentence তৈরি হয়।

## পুরো Pipeline

<ConceptAnim name="llm-pipeline" caption="Text থেকে prediction — step-by-step data flow" />

```mermaid
flowchart TD
    text["📝 Text"]:::a --> tokenizer["🔤 Tokenizer"]:::b
    tokenizer --> vocab["📖 Vocabulary"]:::b
    vocab --> embedding["🔢 Embedding"]:::b
    embedding --> transformer["🧠 Transformer"]:::b
    transformer --> logits["📊 Logits"]:::b
    logits --> softmax["⚡ Softmax"]:::b
    softmax --> nextToken["🎯 Next Token"]:::c
    classDef a fill:#4F46E5,color:#fff
    classDef b fill:#10B981,color:#fff
    classDef c fill:#F59E0B,color:#fff
```

আমরা এখন **শুধু প্রথম ২টা step** করব (Tokenizer + Vocabulary)। বাকিগুলো পরের Part-এ।

## GPT-4 vs আমাদের Model

| | GPT-4 | আমাদের Tiny Model |
|---|---|---|
| Training data | Trillions of tokens | ~30 words |
| Vocabulary | ~100,000 tokens | 12 words |
| Parameters | Billions | ~144 (Part 2-তে) |
| Architecture | Transformer | Bigram (Part 2) |

স্কেল আলাদা, কিন্তু **idea একই**: আগের text দেখে next token predict করা।

## তুমি কী শিখলে?

- LLM = next token prediction machine
- Input text → Model → Probability distribution → Pick one token
- আমরা ছোট scale-এ same idea implement করব

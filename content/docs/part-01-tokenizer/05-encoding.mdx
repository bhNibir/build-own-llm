# Encoding / Decoding

<ConceptAnim name="llm-pipeline" caption="Encode sentence to number array" />

Vocabulary আছে। এখন sentence কে number list-এ convert করব — এটাই **Encoding**। উল্টোটা **Decoding**।

```mermaid
flowchart LR
    A["📝 Text"]:::text --> B["Encode"]:::enc
    B --> C["🔢 IDs"]:::ids
    C --> D["Decode"]:::dec
    D --> E["📝 Text"]:::text
    classDef text fill:#4F46E5,color:#fff,stroke:#3730A3
    classDef enc fill:#10B981,color:#fff,stroke:#047857
    classDef ids fill:#F59E0B,color:#fff,stroke:#D97706
    classDef dec fill:#6366F1,color:#fff,stroke:#4338CA
```

## Encoding

Sentence → Number list

```
"i like apple"  →  [7, 9, 0]
"fruit is healthy"  →  [4, 8, 5]
```

প্রতিটা word-কে তার vocabulary ID-তে map করা।

## Decoding

Number list → Sentence (উল্টো)

```
[4, 8, 5]  →  "fruit is healthy"
```

## গুরুত্বপূর্ণ বোঝাপড়া

> Model এখনও word বুঝে না। শুধু **number** বুঝে।
>
> `"apple"` দেখে না → `0` দেখে
> `"like"` দেখে না → `9` দেখে

এটাই Tokenizer + Vocabulary + Encoding-এর মূল উদ্দেশ্য।

## তুমি কী শিখলে?

- **Encode** = text → numbers
- **Decode** = numbers → text
- Model শুধু number array নিয়ে কাজ করে

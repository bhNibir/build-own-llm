# Vocabulary

<ConceptAnim slug="part-01-tokenizer/04-vocabulary" />

Tokenizer sentence কে word-এ ভাগ করল। এখন প্রশ্ন: model কীভাবে এই word-গুলো বুঝবে? উত্তর: **number দিয়ে**। আর সেই number-এর dictionary-ই হলো **Vocabulary** — সব unique token-এর list, প্রতিটার একটা স্থায়ী ID সহ।

## Vocabulary তৈরি

Dataset-এর সব unique word collect করো, তারপর প্রতিটাকে একটা ID দাও:

```mermaid
flowchart LR
    dataset["📂 Dataset"]:::d --> unique["✨ Unique Words"]:::u
    unique --> sorted["🔤 Sorted List"]:::s
    sorted --> mapping["🔢 Word → ID"]:::m

    classDef s fill:#F59E0B,color:#fff,stroke:#D97706
    classDef m fill:#EC4899,color:#fff,stroke:#DB2777
```

Sorted করে ID দিলে lookup deterministic হয় — একই corpus-এ বারবার একই mapping পাবে।

## আমাদের Vocabulary

আমাদের fruit corpus থেকে ১২টা unique word:

| Word | ID |
|------|----|
| apple | 0 |
| banana | 1 |
| eat | 2 |
| eats | 3 |
| fruit | 4 |
| he | 5 |
| healthy | 6 |
| i | 7 |
| is | 8 |
| like | 9 |
| mango | 10 |
| you | 11 |

মোট **12টা unique word** = Vocabulary size = 12। ছোট, কিন্তু পুরো pipeline চালানোর জন্য যথেষ্ট।

## কোড

`code/part-01/vocabulary.ts`-এ দুটো map থাকে — দুদিকেই যেতে পারার জন্য:

- **stoi** (string → int): `"apple"` → `0`
- **itos** (int → string): `0` → `"apple"`

একদিক শুধু encode-এর জন্য; অন্যদিক decode-এর জন্য। দুটোই লাগবে।

## GPT-এর Vocabulary

| Model | Vocab Size |
|-------|-----------|
| আমাদের | 12 |
| GPT-2 | 50,257 |
| GPT-4 | ~100,000 |

স্কেল আলাদা, concept same — শুধু আমাদেরটা টেবিল খুলে দেখা যায়।

## তুমি কী শিখলে?

- **Vocabulary** = সব unique token-এর list + ID mapping
- Model শুধু number বুঝে, string নয় — তাই `stoi` আর `itos` দুটো direction-এ lookup দরকার
- Vocab size ছোট হলে intuition পরিষ্কার থাকে; বড় model-এ শুধু list লম্বা হয়

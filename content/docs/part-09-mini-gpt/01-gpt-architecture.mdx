# 🏛️ GPT Architecture

<ConceptAnim name="llm-pipeline" caption="GPT = stack of blocks" />

সব building block এক জায়গায় — **GPT architecture**। Token in → transformer blocks → next token out।

<Callout type="idea">
💡 GPT = **Generative Pre-trained Transformer** — decoder-only, causal self-attention, autoregressive generation।
</Callout>


## Transformer Block (recap)

```mermaid
flowchart TD
    input[Input] --> norm1[LayerNorm]
    norm1 --> attn[Multi-Head Attention]
    attn --> res1["+ (Residual)"]
    input --> res1
    res1 --> norm2[LayerNorm]
    norm2 --> mlp[MLP Feed Forward]
    mlp --> res2["+ (Residual)"]
    res1 --> res2
    res2 --> output[Output]
    style attn fill:#FFD700
```

## Components Map

| Component | Module | Role |
|-----------|--------|------|
| Tokenizer | 1 | Text → IDs |
| Embedding | 6 | ID → vector |
| Attention | 7 | Context mixing |
| Transformer block | 8 | Full block |
| Training | 6 | Loss + update |
| Generation | 2, 6 | Autoregressive |

# Train Mini GPT

<ConceptAnim slug="part-09-mini-gpt/02-train" />

Architecture বুঝে গেছ — এখন সেই stack-কে **train** করব fruit dataset-এ। Module 6-এর training loop-এর same pattern: forward pass → cross-entropy loss → backprop → weight update। শুধু এবার model একটু বড় ভাবতে পারো।

<Callout type="warn">
⚠️ Browser-এ full transformer training ভারী — এই Playground-এ **simplified word-level trainer** চলে (**esbuild-wasm** runtime)। Architecture lesson-এ যা শিখেছ, সেই loop-এর same pattern: forward → loss → backward → update।
</Callout>

## Dataset

Fruit sentences — Module 1 থেকেই চেনা corpus:

```
"i like apple"
"apple is fruit"
"fruit is healthy"
"i like banana"
...
```

<Callout type="tip">
💡 Full Mini GPT-তে ৪টা transformer block + Adam optimizer থাকে। Playground-এ fruit dataset-এ **word-level neural LM** train করব — same training loop, ছোট architecture। Idea শিখতে এটাই যথেষ্ট।
</Callout>

## Training Loop

```ts
for (let step = 0; step < maxSteps; step++) {
  const { input, target } = getBatch();
  const logits = gpt.forward(input);       // (B, T, V)
  const loss = crossEntropy(logits, target);
  loss.backward();
  optimizer.step();
  if (step % 100 === 0) console.log(`loss: ${loss.value}`);
}
```

# 👁️ Module 7 — Attention

Neural bigram শুধু **১টা আগের token** দেখে। Real sentence-এ দূরের word-ও গুরুত্বপূর্ণ। **Attention** সব token-এর মধ্যে relevance measure করে।

<Callout type="idea">
💡 Attention = "এই word-এর জন্য sentence-এর কোন অংশ সবচেয়ে relevant?" — search engine-এর মতো।
</Callout>

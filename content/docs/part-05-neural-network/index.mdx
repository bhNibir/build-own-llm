# Module 5: Neural Network

Math + Autograd শেষ — এখন সেই tools দিয়ে **সত্যিকারের neural network** বানাবো। Single Neuron থেকে শুরু করে Layer, তারপর MLP — শেষে **XOR** solve করব।

<Callout type="idea">
একটা **Neuron** = weighted sum + activation function। Layer stack করলে **MLP (Multi-Layer Perceptron)** — GPT-এর দূরবর্তী পূর্বপুরুষ!
</Callout>

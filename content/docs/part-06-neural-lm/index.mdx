# Module 6 — Neural Language Model

Bigram model **counting** দিয়ে কাজ করে। Module 6-এ আমরা same task neural network দিয়ে করব — **embedding**, **weight matrix**, **loss**, **training loop**, এবং **generation**।

<Callout type="idea">
💡 Bigram-এর count table = fixed memory। Neural LM-এ weights **gradient descent** দিয়ে learn হয় — data বাড়লে pattern capture করতে পারে।
</Callout>

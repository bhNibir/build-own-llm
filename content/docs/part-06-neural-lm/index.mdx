# Module 6 — Neural Language Model

Module 2-এ Bigram **counting** দিয়ে next word predict করতাম। কাজ করত — কিন্তু count table fixed memory; data বাড়লেও smart pattern শেখে না।

Module 5-এ neuron, layer, MLP দেখেছ। এখন সেই neural network দিয়ে **same next-token task** করব — Embedding, Weight Matrix, Loss, training loop, আর generation।

<Callout type="idea">
Bigram-এর count table = fixed memory। Neural LM-এ weights **gradient descent** দিয়ে learn হয় — data বাড়লে pattern capture করতে পারে।
</Callout>

```mermaid

    A["🔢 Token ID"]:::input --> B["📊 Embedding E"]:::process
    B --> C["⚖️ Weight W"]:::process
    C --> D["📈 Softmax"]:::process
    D --> E["🎯 Next token"]:::output
    classDef input fill:#4F46E5,color:#fff,stroke:#3730A3
    classDef process fill:#10B981,color:#fff,stroke:#047857
```

Pipeline সোজা: token ID → Embedding vector → Weight Matrix দিয়ে logits → Softmax দিয়ে probability → next token। Idea Bigram-এর মতোই; শুধু memory এখন learned weights।

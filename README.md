# build-own-llm

Bangla hands-on LLM learning resource — zero থেকে TypeScript দিয়ে Language Model বানানো শেখা।

Run development server:

```bash
bun dev
```

Run code examples:

```bash
bun part-01   # Tokenizer + Vocabulary demo
bun part-02   # Bigram model train + generate
```

Open http://localhost:3000 with your browser to see the result.

## Explore

- `content/docs/` — Bangla MDX lessons (Fumadocs)
- `code/` — Runnable TypeScript examples per Part
- `lib/source.ts` — Content source adapter

| Route          | Description              |
| -------------- | ------------------------ |
| `app/(home)`   | Landing page             |
| `app/docs`     | Documentation / course   |
